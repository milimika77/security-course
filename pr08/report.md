# Практическая работа №9. Следы вредоносного ПО в Linux

## Цель работы

Изучить способы обнаружения следов вредоносного программного обеспечения в Linux, исследовать механизмы автозапуска, процессы и сетевые соединения, а также освоить методы удаления обнаруженных следов.

## 1. Что было посажено

| Механизм           | Место                   | Команда/файл                     |
| ------------------ | ----------------------- | -------------------------------- |
| Cron               | crontab пользователя    | /tmp/.hidden_malware/backdoor.sh |
| Systemd            | ~/.config/systemd/user/ | system-helper.service            |
| Shell Profile      | ~/.bashrc               | /tmp/.hidden_malware/backdoor.sh |
| Процесс            | /tmp/.hidden_malware/   | listener.sh                      |
| Сетевое соединение | TCP порт 4444           | nc                               |

## 2. Обнаружение подозрительных процессов

Для поиска подозрительных процессов использовалась команда:

ps aux | grep '/tmp'

Были обнаружены процессы, запущенные из каталога /tmp/.hidden_malware. Подобное расположение файлов считается подозрительным, поскольку временные каталоги часто используются вредоносным программным обеспечением для сокрытия своей деятельности.

Дополнительно было исследовано дерево процессов с помощью команды:

ps auxf

Это позволило установить взаимосвязь между процессами backdoor.sh, listener.sh и их дочерними процессами.

## 3. Анализ сетевых соединений

Для поиска открытых портов использовалась команда:

ss -tulnp

В результате был обнаружен открытый TCP-порт 4444, прослушиваемый процессом nc.

Дополнительно была выполнена команда:

sudo lsof -i :4444

Утилита lsof позволила установить связь между сетевым портом, процессом и исполняемым файлом. Таким образом был подтверждён запуск имитации backdoor-службы.

## 4. Анализ автозапуска

### Cron

В пользовательском cron были обнаружены следующие записи:

@reboot /tmp/.hidden_malware/backdoor.sh &
*/5 * * * * /tmp/.hidden_malware/backdoor.sh &

Записи обеспечивали автоматический запуск скрипта после загрузки системы и каждые пять минут.

### Systemd

Был обнаружен пользовательский сервис:

system-helper.service

Содержимое unit-файла:

ExecStart=/tmp/.hidden_malware/backdoor.sh
Restart=always

Сервис автоматически перезапускал скрипт при его завершении, обеспечивая устойчивость работы.

### Bashrc

В файле ~/.bashrc была обнаружена строка:

/tmp/.hidden_malware/backdoor.sh &

Данная команда запускала скрипт при каждом открытии терминала пользователем.

## 5. Анализ открытых файлов

Для анализа файлов, используемых процессом, применялась команда:

sudo lsof -p PID

Также была выполнена проверка удалённых, но всё ещё используемых файлов:

sudo lsof | grep deleted

Были обнаружены записи типа (deleted), что демонстрирует возможность существования процессов, продолжающих использовать удалённые файлы. Подобный механизм часто применяется вредоносным программным обеспечением для сокрытия следов.

## 8. Очистка системы

После завершения расследования были удалены все следы учебного вредоносного ПО:

* удалён пользовательский сервис system-helper.service;
* очищен пользовательский cron;
* удалены записи из ~/.bashrc;
* завершены процессы backdoor.sh, listener.sh и nc;
* удалён каталог /tmp/.hidden_malware.

Финальная проверка диагностическим скриптом показала отсутствие следов учебного вредоносного ПО.
